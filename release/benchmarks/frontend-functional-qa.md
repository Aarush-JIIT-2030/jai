### Detailed Console Inspections:

1. **CONSOLE-01: Executive Overview (`activeNav === "Overview"`)**
   - **Features:** Houses the primary WebGL 3D network topology canvas with HUD telemetry overlays, threat distribution doughnut charts, 4 primary KPI cards (Total Flows, Containment Rate, Active Policies, False Block Rate), and 1-click scenario trigger buttons.
   - **QA Verdict:** Functional. Real-time updates render smoothly; mode toggles between 3D WebGL and 2D SVG topology without state loss.

2. **CONSOLE-02: Live Ingress Stream (`activeNav === "Live Streams"`)**
   - **Features:** Visualizes live network flow ingress with simulated microsecond timestamps, protocol breakdown, and color-coded action badges (`ALLOW` in emerald, `BLOCK` in rose).
   - **QA Verdict:** Functional. Integrated with `/api/flows/sample` to render authentic evaluation flows.

3. **CONSOLE-03: Threat Intelligence (`activeNav === "Threat Detection"`)**
   - **Features:** Deep-dive inspection of Agent 1. Displays confidence distributions across the 5 threat classes (`BENIGN`, `DOS`, `PORT_SCAN`, `DDOS`, `BRUTE_FORCE`) and feature contribution waterfalls.
   - **QA Verdict:** Functional. Correctly distinguishes high-confidence attacks from borderline traffic.

4. **CONSOLE-04: Zero-Day Isolation (`activeNav === "Zero-Day Anomalies"`)**
   - **Features:** Visualizes Agent 2's unsupervised anomaly score spectrum ($[-1.0, 1.0]$), highlighting deviations in tail feature distributions that evade supervised signatures.
   - **QA Verdict:** Functional. Anomaly threshold slider interactively filters suspicious flow clusters.

5. **CONSOLE-05: Correlation Hub (`activeNav === "Correlation Hub"`)**
   - **Features:** Displays multi-flow temporal attack graphs generated by Agent 3. Correlates distributed port sweeps and DDoS cascades across sliding time windows.
   - **QA Verdict:** Functional. Integrated with `/api/correlation/groups` showing active cluster formations.

6. **CONSOLE-06: Policy Guardrails (`activeNav === "Policy Guardrails"`)**
   - **Features:** Live inspection of simulated adaptive defense policies. Shows target IP/CIDR, trigger threat, confidence score, and remaining TTL step countdown. Includes interactive `/api/policies/test` pre-filter simulator.
   - **QA Verdict:** Functional. Rules display live expiration status; simulation guarantees zero physical firewall modification.

7. **CONSOLE-07: Analyst Studio (`activeNav === "Analyst Studio"`)**
   - **Features:** Agent 5 automated incident response console. Generates NIST-structured incident briefs, threat narratives, and recommended firewall configurations.
   - **QA Verdict:** Functional. Markdown rendering produces clean, copyable incident documentation.

8. **CONSOLE-08: Causal Replay (`activeNav === "Causal Replay"`)**
   - **Features:** Time-travel debugging interface. Allows the SOC analyst to pause replay, scrub forward/backward across the 114,185 flow sequence, inspect pre-filter decisions, and verify causality invariants.
   - **QA Verdict:** Functional. Step scrubber updates flow inspection pane instantly.

9. **CONSOLE-09: Benchmark Suite (`activeNav === "Evaluation Suite"`)**
   - **Features:** Scientific evaluation dashboard presenting precision, recall, F1, per-class containment, and automated mathematical identity verification cards.
   - **QA Verdict:** Functional. Identies display verified green checks confirming exact packet conservation.

10. **CONSOLE-10: Submission Hub (`activeNav === "Submission Manager"`)**
    - **Features:** Artifact management center displaying file sizes, record counts, and SHA-256 hashes for `classification.csv`, `policy.csv`, and `replay.csv`.
    - **QA Verdict:** Functional. Displays `READY_FOR_SUBMISSION` status badge with zero contract violations.

11. **CONSOLE-11: System Diagnostics (`activeNav === "System Architecture"`)**
    - **Features:** Architecture diagram showing inter-agent latency, memory utilization ($< 150$ MB), GPU/CPU load, and backend REST endpoint health probes.
    - **QA Verdict:** Functional. All backend routes return HTTP 200 OK.
